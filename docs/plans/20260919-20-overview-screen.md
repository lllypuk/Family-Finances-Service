# План 20. Экран «Обзор»

## Overview

«Главная» показывает только текущий месяц. Сервер давно умеет больше — `GET /stats/summary?from&to` и
`GET /stats/monthly` (план 10), а экрана над ними нет: это незакрытая половина плана 11.

- Экран «Обзор»: период чипами, итоги с дельтой, столбики дохода и расхода за 12 месяцев, топ категорий.
- Тап по категории — операции этой категории за период; тап по столбику — период «этот месяц года».
- Только клиент, `0.12.0` (после плана 19). Контракт и сервер не меняются.

Не входит: произвольный диапазон дат, мультивыбор и массовое удаление операций (вторая половина плана 11),
бюджеты и последние операции за период — сервер считает их на сегодня.

## Solution Overview

**Вход — строка «Обзор ›» под итогами «Главной»,** не вкладка: панель полна. «Главная» остаётся текущим
месяцем.

**Периоды считаются в зоне семьи** (`session.zone`), не по часам телефона — в отличие от фильтра операций:
итоги экрана и сервер обязаны говорить об одном дне.

| Чип | Границы |
|---|---|
| Этот месяц | 1-е число … сегодня |
| Прошлый месяц | полный прошлый месяц |
| 3 месяца | 1-е число месяца два месяца назад … сегодня |
| Год | 1-е число месяца одиннадцать месяцев назад … сегодня |
| (столбик) | полный выбранный месяц; для текущего — по сегодня |

**График всегда за 12 месяцев, период на нём подсвечен.** Один столбик «этого месяца» ничего не показывает;
год рядом даёт масштаб. Ряд `monthly` грузится один раз на экран, `summary` — на каждую смену периода. Тап
по столбику выбирает месяц — это и есть «произвольный месяц» без выбора дат.

**Дельта — «к предыдущему периоду», и только при `has_previous_data`.** Сервер сравнивает с отрезком той же
длины вплотную перед выбранным: для «этого месяца» 19-го числа это 19 дней до 1-го, а не прошлый месяц
целиком. Подпись говорит именно это, без слов «к прошлому месяцу».

**`budgets` и `recent` из `summary` не показываются.** Они посчитаны на сегодня и за прошлый год врали бы.

**Расшифровка категории — диапазон дат в фильтре операций.** Новый `TransactionPeriod.RANGE` с `from` / `to`;
переход несёт тип, категорию и границы периода, а `AppScreen.Transactions` — цель «назад» в «Обзор» с тем же
периодом, как сейчас со сверкой. Чипа `RANGE` в ряду фильтров нет: это состояние «открыт снаружи», как `MONTH`.

## Technical Details

```
Обзор                                  ‹ назад
( Этот месяц ) ( Прошлый ) ( 3 мес ) ( Год )

Остаток                          +84 300,00 ₽
Доход            312 000,00        +4 %
Расход           227 700,00       −11 %
к предыдущему периоду той же длины

 ▂▃ ▃▄ ▂▃ ▄▅ ▃▃ ▅▆ ▄▄ ▃▅ ▄▆ ▅▅ ▄▆ █▇      доход ▌ расход ▌
 о  н  д  я  ф  м  а  м  и  и  а  с       выбранные месяцы — в полную силу, остальные приглушены

Расходы по категориям
┌──────────────────────────────────────────┐
│ Продукты            68 400,00      30 % ›│
│ Ипотека             62 000,00      27 % ›│
│ …                                        │
└──────────────────────────────────────────┘
Доходы по категориям
┌──────────────────────────────────────────┐
│ Зарплата           290 000,00      93 % ›│
└──────────────────────────────────────────┘
```

- Столбики парные, общий масштаб по максимуму из доходов и расходов ряда; высота нулевого месяца — ноль, не
  минимальная черта. Геометрия — чистая функция `barGeometry(months)`.
- Категории — все, что прислал сервер, по убыванию суммы; свёртки «Прочее» нет. Цвет категории — как на «Главной».
- Пустой период (`transaction_count == 0`): итоги нулями, вместо списков — «За период операций нет»; график остаётся.
- Ошибка `summary` при смене периода не стирает график и чипы: отказ показывается на месте итогов с «Повторить».
- «Назад» — на «Главную»; возврат из операций — в «Обзор» с тем же периодом.

`TransactionFilters`: `from: LocalDate?`, `to: LocalDate?` — только при `RANGE`. Строка `Saver`'а растёт до семи
полей; чтение — по индексу, а не деструктуризацией, и пяти-польная строка прежнего формата читается как раньше.

## Post-Completion

**Проверка на телефоне:** итоги «Этого месяца» совпадают с «Главной»; «Год» — сумма столбиков равна итогам;
тап по категории за «3 месяца» открывает операции, сумма которых равна строке; «назад» возвращает в «Обзор» с
тем же периодом; поворот экрана и убийство процесса сохраняют период.

**Граница суток:** телефон в другой зоне, чем семья, — расшифровка категории несёт явные даты из «Обзора», а
не пересчитывает их по часам телефона; проверить около полуночи необязательно, достаточно теста модели.

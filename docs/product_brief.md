# Product Brief - Family Finances Service

## 🎯 Зачем мы создаем этот продукт?

### Проблема
Современные семьи сталкиваются с трудностями в управлении личными финансами:
- Отсутствие единой системы учета доходов и расходов всех членов семьи
- Сложность планирования семейного бюджета и достижения финансовых целей
- Недостаток прозрачности в семейных тратах
- Отсутствие инструментов для анализа финансовых привычек

### Наше решение
Family Finances Service - это self-hosted сервис для управления семейными финансами, который обеспечивает:
- **Централизованный учет** всех доходов и расходов семьи
- **Умное планирование** бюджета с учетом приоритетов
- **Аналитику** финансового поведения и трендов
- **Совместное управление** финансами для всех членов семьи

## 🏆 Видение продукта

### Миссия
Помочь семьям принимать осознанные финансовые решения через простые и понятные инструменты управления деньгами.

### Видение на 1 год
Стать основным self-hosted решением для семей, обеспечивающим надежное и безопасное управление семейными финансами с минимальными требованиями к инфраструктуре.

## 👥 Целевая аудитория

### Основные пользователи
- **Семьи с детьми** (25-45 лет) - основная аудитория
- **Молодые пары** (22-35 лет) - планирующие совместный бюджет
- **Self-hosted энтузиасты** - пользователи, предпочитающие контроль над своими данными

### Пользовательские сценарии
1. **Семейный бюджет**: Планирование и контроль семейных расходов
2. **Совместные цели**: Накопления на отпуск, покупку квартиры и т.д.
3. **Детские финансы**: Управление карманными деньгами и целями детей
4. **Аналитика трат**: Понимание куда уходят деньги семьи

## 🛠️ Детальная функциональность

### 💳 Управление транзакциями
- **CRUD операции**: Создание, просмотр, редактирование, удаление
- **Массовые операции**: Импорт из CSV/Excel, групповое редактирование
- **Шаблоны транзакций**: Повторяющиеся платежи (зарплата, аренда, подписки)
- **Разделение счетов**: Split transactions между категориями и участниками
- **Прикрепление файлов**: Чеки, фото, документы к транзакциям
- **Валюты**: Поддержка множественных валют с автоконвертацией

### 📊 Система бюджетирования
- **Периодические бюджеты**: Месячные, квартальные, годовые
- **Категориальные лимиты**: Ограничения по типам трат
- **Семейные лимиты**: Общие и индивидуальные бюджеты
- **Автоматические переносы**: Неизрасходованные средства в следующий период
- **Уведомления**: Alerts при достижении 80%, 90%, 100% лимита
- **Гибкие правила**: Исключения для экстренных трат

### 🎯 Финансовые цели
- **Накопительные цели**: Отпуск, покупки, образование
- **Целевые сроки**: Календарные планы достижения
- **Автоматические взносы**: Регулярное откладывание средств
- **Прогресс-трекинг**: Визуализация достижения целей
- **Семейные цели**: Совместные накопления всех участников

### 📈 Аналитика и отчеты
- **Dashboard**: Обзор ключевых метрик на главном экране
- **Тренды расходов**: Графики по периодам и категориям
- **Сравнительный анализ**: Месяц к месяцу, год к году
- **Детализированные отчеты**: По участникам, категориям, периодам
- **Экспорт данных**: PDF отчеты, CSV выгрузки
- **Прогнозы**: Предсказание трат на основе истории

### 👥 Управление ролями и правами
- **Family Admin**: Полный доступ к управлению семьей и финансами
- **Family Member**: Добавление трат, просмотр семейной аналитики
- **Child**: Ограниченный доступ, лимиты на траты
- **View Only**: Только просмотр данных без редактирования
- **Approval Workflow**: Согласование крупных трат между участниками
- **Уведомления**: Семейные alerts о важных финансовых событиях

## 💼 Модель распространения

### Self-hosted (Open Source)
- **Бесплатное решение**: MIT лицензия, полный доступ к исходному коду
- **Один экземпляр = одна семья**: Каждая семья разворачивает свой Docker-контейнер
- **Полный контроль данных**: Данные хранятся локально у пользователя
- **Минимальные требования**: Один Docker-контейнер (~50MB), SQLite база данных

## 🔒 Ключевые принципы

### Безопасность
- Данные хранятся локально, не передаются третьим лицам
- Bearer-токены с хранением сессий на сервере, ролевой доступ
- Лимитер попыток входа в самом приложении, а не только в reverse proxy

### Производительность
- Время отклика API < 200ms
- Минимальное потребление ресурсов (SQLite, один процесс)
- Простое резервное копирование (один файл БД)

### Пользовательский опыт
- Простота использования для всех возрастов
- Быстрая настройка: одна CLI-команда `setup` — и можно входить с телефона

## 📊 Конкурентные преимущества

### Наши сильные стороны
- **Семейный фокус**: Специализация именно на семейных финансах
- **Self-hosted**: Один Docker-образ (~50MB), никаких внешних зависимостей
- **Простота развертывания**: SQLite база данных, не требует отдельного сервера БД
- **API-first подход**: Возможность встраивания в любые приложения
- **Privacy by Design**: Данные хранятся локально у пользователя

### Отличия от конкурентов
- Большинство решений ориентированы на индивидуальных пользователей
- Self-hosted: полный контроль над своими данными
- Один Docker-образ без сложной инфраструктуры
- Фокус на совместном семейном планировании
- Учет специфики семейного бюджета (дети, совместные цели)

## 📱 Платформа

Единственный клиент — Android-приложение поверх JSON API ([spec 005](specs/005-api-only-redesign.md)).
Веб-интерфейса у сервиса нет; первичная настройка (семья и администратор) — CLI-команда `setup` на сервере.

## ⚙️ Технические требования

### 🌐 API архитектура
- **REST API**: Стандартные HTTP методы и статус-коды, один JSON-конверт ошибок
- **API документация**: OpenAPI 3.1 — `docs/api/openapi.yaml`, из него генерируется Android-клиент

### 🔐 Безопасность
- **Локальное хранение данных**: Все данные на сервере пользователя
- **Аутентификация**: bearer-токены, на сервере хранится только хеш; 30 дней без активности,
  не дольше 180 дней; лимитер логина по IP и email (A-01, A-09 в [spec 005](specs/005-api-only-redesign.md))
- **Валидация ввода**: Комплексная валидация всех входных данных
- **Data backup**: Копирование файла SQLite базы данных

### 📊 Производительность
- **Response time**: < 200ms для 95th percentile
- **База данных**: SQLite — встроенная, не требует отдельного сервера
- **Развертывание**: Один Docker-образ с минимальным потреблением ресурсов
- **Бэкапы**: Простое копирование файла базы данных

### 🔗 Возможные интеграции (долгосрочно)
- **Банковские API**: Open Banking для автоматического импорта
- **Экспорт данных**: CSV, JSON для переноса и анализа
- **Messaging platforms**: Telegram бот для быстрого ввода трат
